The status is changed in the top right corner of the task card. The card's border colour matches the status, so the progress of the whole advancement is visible at a glance.

## What the statuses mean {#znaczenie-statusow}

| Status | Colour | When to use it |
|---|---|---|
| **Created** | grey | The task is written down, but work has not started. Every new task has this status. |
| **In progress** | blue | The mentee is working on the task. |
| **Submitted** | orange | The task is done and waits for the mentor's assessment. |
| **Completed** | green | The mentor accepted the task as done. |
| **Failed** | red | The task could not be done (e.g. the camp did not take place). You can add a new task instead. |

The status is also in the PDF (“Task list” layout).

## A typical workflow with a mentor {#typowy-przebieg-pracy-z-opiekunem}

1. The mentee adds and describes tasks – status **Created**.
2. The mentor reads them and leaves [comments](/pomoc/komentarze), e.g. “Add the date”. The mentee improves the text and marks the notes as resolved.
3. When the plan is agreed, the mentee starts – **In progress**.
4. After doing the task the mentee sets **Submitted** and briefly describes the result in a comment.
5. The mentor checks it and sets **Completed**, or leaves a note and sets it back to **In progress**.

> [!TIP]
> The status is just information – anyone can change it. Agree with your mentor who sets “Completed”.
